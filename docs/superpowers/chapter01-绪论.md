## 1.1 研究背景与意义

### 1.1.1 地震应急场景下的信息需求与问答痛点

地震及其次生灾害突发性强、影响面广，应急阶段的信息服务直接关系到公众自救互救效率与舆情稳定。一方面，公众需要快速了解震情概况（时间、地点、震级、影响范围等）以及“如何应对”“如何避险”等可执行指引；另一方面，基层宣传与培训场景也需要将分散在规范、预案与科普材料中的知识以**可问答、可检索**的形式提供给使用者。

传统方式主要依赖门户网站、固定栏目文档与人工咨询，存在三方面局限：**检索路径固定**，难以用自然语言一次性表达复杂意图；**内容更新与多源对齐成本高**，同一事实可能在不同表格、文本中重复或不一致；**交互门槛偏高**，非专业用户难以在大量文档中定位到与自身处境匹配的段落。因此，以**自然语言问答**为交互形态的地震应急信息服务，具有明确的应用需求。

近年来，Web 与开放数据的发展使得地震目录、区域划分与应急科普文本能够以结构化或半结构化形式积累，为在机器可读知识基础上构建问答能力提供了数据条件。如何在应急这一高风险、强事实领域，既保证回答的**时效与可追溯**，又控制系统建设与运维成本，成为值得研究的问题。

### 1.1.2 大模型应用中的事实性与可核对性挑战

大语言模型（Large Language Model, LLM）在开放域对话、摘要与写作辅助等任务上表现突出，但在地震应急等专业场景中，若**仅依赖模型参数内隐知识**进行生成，往往面临以下问题：

（1）**事实性错误与幻觉**。模型可能编造不存在的震级、地点或处置步骤，且输出形式流畅，增加了误判风险。  
（2）**对结构化事件信息利用不足**。震级筛选、分地区统计等需求，本质上适合由数据库或图查询精确完成，若完全交给自由生成，难以保证与库内记录一致。  
（3）**知识时效与出处不明**。应急指引与预案可能修订，仅依赖训练截断日期之前的参数记忆，无法可靠反映当前库内版本；同时，用户难以核对答案所依据的具体条文或记录。

针对上述问题，业界与学界普遍从两条路径增强生成：**检索增强生成（Retrieval-Augmented Generation, RAG）**在非结构化语料中检索相关片段，作为生成的显式依据；**知识图谱（Knowledge Graph, KG）**将实体与关系显式建模，支持可解释的子图查询与约束推理。二者各有侧重：向量检索擅长语义相近的段落召回，图谱擅长精确的结构化约束与关系遍历。在地震应急问答中，将**图谱查询与向量检索协同**起来，使模型在统一提示中同时获得“结构化事实摘要”与“相关文本依据”，有助于在交互自然度的前提下提升**可核对性与稳定性**。此外，通过**参数高效微调（如 LoRA）**在本地部署的小规模基座模型上注入领域表达习惯，可在有限算力条件下改善回答风格与任务贴合度。

**研究意义**可概括为：  
**理论层面**，对“图谱上下文 + 向量片段 + 领域微调模型”的协同机制进行梳理与形式化，丰富应急领域问答中混合知识增强方法的讨论；  
**应用层面**，形成可离线部署的技术路线，便于在校园、机房或专网环境中复现与演示，服务于地震应急科普与教学实验场景。

## 1.2 国内外研究现状

### 1.2.1 应急领域知识工程与问答系统

早期应急与灾害领域信息系统多以**数据库、知识库与规则系统**为主，强调流程化处置与预案匹配，自然语言问答能力有限。随着知识工程与本体建模的发展，领域概念、角色与处置步骤可被显式表示，为后续与图数据库、推理引擎结合奠定了基础。国内外在**灾害数据共享、应急地理信息、事件目录服务**等方面积累了大量实践，但在“面向公众的自然语言问答”上，往往仍需人工整理 FAQ 或关键词检索，**语义理解与多轮澄清**能力不足。近年来，部分工作将通用搜索引擎或对话系统引入应急场景，但**专业事实与条文的精准对齐**仍是难点。该方向的研究为在地震应急中引入**结构化知识载体**（如图谱）提供了问题背景与数据组织经验。

### 1.2.2 知识图谱增强的语言模型与问答

知识图谱问答（KBQA）长期依赖语义解析、图匹配与神经网络排序等技术，将自然语言问题映射为结构化查询（如 SPARQL 或图模式）[1]。随着预训练语言模型兴起，**图谱表示学习与语言模型联合建模**成为热点，例如利用图神经网络或图谱嵌入增强实体链接与多跳推理 [2]。在大模型时代，研究重心进一步转向**如何用图谱约束或丰富 LLM 的上下文**：包括从图谱检索相关子图并线性化为文本、将图谱事实作为提示的一部分，以及图谱与检索器联合排序等。相关工作表明，在需要**精确实体关系**的任务上，纯文本检索不足以替代结构化查询；但图谱构建成本与查询覆盖范围也限制了单独使用图谱时的**语义泛化**能力。地震应急场景中，震区、震级、应急主题与步骤等要素适合图谱化，与该方向具有较好契合度。

### 1.2.3 检索增强生成（RAG）及其与图谱的结合

RAG 通过“检索—拼接—生成”范式，将外部语料以片段形式注入提示，显著缓解纯参数记忆带来的事实漂移，代表性框架见文献 [3]。在实现上，稠密向量检索（基于双塔编码器或句向量）与稀疏检索（BM25 等）常被采用；针对长文档，还需研究**分块策略、重排序与上下文长度控制**。进一步地，**GraphRAG、KGRAG** 等工作尝试将社区检测、图遍历与向量检索结合，以兼顾全局结构与局部语义 [4][5]。与通用开放域相比，地震应急语料规模相对可控，但更强调**条文式步骤与一致性表述**，因此向量 Top-K 检索与人工或半自动整理的应急知识库结合仍具实效。现有研究的不足在于：**何时触发图谱查询、何时依赖向量检索、二者在提示中的优先级与冲突消解**，在领域系统中往往需要结合业务规则具体设计，通用框架难以直接套用。

### 1.2.4 领域大模型微调与参数高效方法

将通用 LLM 适配到垂直领域，常见路径包括**继续预训练、全量监督微调（SFT）与基于人类反馈的对齐**等。全量微调对显存与数据量要求较高。**参数高效微调（Parameter-Efficient Fine-Tuning, PEFT）**仅训练少量附加参数即可近似全量效果，其中 **LoRA（Low-Rank Adaptation）**通过低秩矩阵分解注入适配层，在消费级硬件上亦可完成小规模实验 [6]。在应急问答中，微调数据可来自指令化的“问题—回答”对或带角色约束的对话，使模型更遵守**分条说明、先安全后细节**等表达规范。需要指出的是，微调主要改善**风格与格式**，并不能单独解决事实错误；因此与 RAG、图谱协同仍是必要补充。

**小结**：应急领域需要**可核对的事实与可执行的文本指引**；图谱与向量检索分别从结构化与语义相似角度提供外部知识；LoRA 等轻量微调有助于在本地算力下提升领域贴合度。将三者纳入统一推理流程并形成可复现系统，仍有明确的工程与方法讨论空间。

## 1.3 研究内容与创新点

### 1.3.1 研究内容

围绕**地震应急自然语言问答**任务，研究工作主要包括：

（1）**知识图谱构建与问题驱动的子图查询**。设计地震事件、区域、应急主题与处置步骤等模式，完成数据导入与约束；依据用户问句中的区域、震级及应急类触发模式，从 Neo4j 中查询相应子图，并序列化为可供模型阅读的图谱上下文。  

（2）**应急知识的向量索引与 Top-K 检索**。对应急知识文本进行分块与句向量编码，在问答阶段按余弦相似度检索若干片段，作为参考资料与图谱上下文一并写入提示。  

（3）**图谱与检索片段的协同融合及本地大模型推理**。在统一提示模板中组织【知识图谱】【参考资料】与【问题】等区块，采用与领域微调一致的对话标记格式；在本地加载基座模型与 LoRA 权重，设置解码参数以抑制重复生成，并针对长提示采用**左侧截断、保留问题与生成标记尾部**的策略，保证推理稳定。  

（4）**系统实现与实验分析**。实现基于 Web 的前后端交互，支持图谱直连查询与数据更新链路；构造对比基线（如关闭图谱上下文或关闭向量检索），从事实一致性、回答完整性与案例分析等角度评价协同方法的有效性。

### 1.3.2 创新点

在综合现有技术路线的基础上，工作重点体现在：

**（1）面向地震应急的图谱—向量协同问答流程。** 将结构化子图查询与稠密向量检索统一纳入单次生成的提示构造过程，使模型同时获得**可解释的结构化摘要**与**语义相关的文本依据**，并给出可落地的触发与拼装规则，区别于仅使用单一知识形态的问答实现。

**（2）与本地 LoRA 微调、长提示截断策略相结合的工程化方法。** 在离线部署约束下，完成模型与嵌入的本地加载与 API 服务封装；针对长上下文场景，明确**分词器截断方向与问题位置**对生成有效性的影响，形成可复现的实现要点。

**（3）可消融的对比实验框架。** 通过配置开关构造仅 LLM、仅图谱增强、仅向量增强与全协同等对比，便于从实验上验证协同机制对回答质量的影响（具体指标与数据集规模见第7章）。

## 1.4 论文结构安排

全书共分八章，结构安排如下：

**第2章** 介绍相关技术与理论基础，包括系统总体架构与数据流、知识图谱与图数据库、文本向量检索、检索增强生成与大语言模型，以及 LoRA 等参数高效微调概念，为后续章节提供术语与符号约定。

**第3章** 给出地震应急问答的任务定义、评价思路及协同方法总体设计，并说明与单一图谱或单一向量检索方案进行对比的实验动机。

**第4章** 阐述知识图谱的模式设计、数据导入流程、面向问题的子图查询与触发规则，以及图谱上下文的生成方式。

**第5章** 介绍应急知识的分块与向量化、Top-K 检索与长度控制，以及参考资料与提示拼装策略。

**第6章** 详细说明图谱上下文与检索片段的融合策略、本地大模型推理与解码配置，以及系统整体实现与关键模块。

**第7章** 给出实验环境、数据集与基线设置，展示实验结果并进行案例分析。

**第8章** 对全文工作进行总结，并讨论不足与未来改进方向。
