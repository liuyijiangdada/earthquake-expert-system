# 论文目录 / 图目录 / 表目录重建设计（媛媛样式）

日期：2026-08-02  
状态：已确认  
目标文件：`华东师范大学硕士论文.docx`  
参考样式：`毕业论文_戚媛媛_答辩版.pdf`

## 目标

丢弃当前混乱的旧目录内容，按戚媛媛论文的结构与观感，重新生成：

1. 主「目录」
2. 独立「图目录」
3. 独立「表目录」

编号格式保持正文现有连字符风格：`图3-1` / `表5-1`（不改为 `图 3.1`）。

## 问题现状

- 主「目录」开头混入了图/表条目，与章节目录缠在一起。
- 「图目录」「表目录」虽独立存在，但页码多为占位 `1`，且与正文题注不完全一致（例如目录曾出现已不存在的图4-3；表编号有重复）。
- 正文现有约 17 个图题注、11 个表题注，应以正文为准重建。

## 目标结构（对齐媛媛）

文档前部顺序：

1. **目录**
   - 入口项：摘要、ABSTRACT、图目录、表目录
   - 章节项：第一章…第六章，以及参考文献、致谢、附录（到三级标题）
   - 不含图/表条目
2. **图目录**（独立标题页/节）
3. **表目录**（独立标题页/节）
4. 正文各章

样式：

- 「目录」「图目录」「表目录」标题居中
- 条目左对齐
- 点引导线（dot leader）+ 右对齐页码
- 字体：中文宋体、西文 Times New Roman

## 实现方案

新建一键脚本：`scripts/rebuild_toc_yuanyuan_style.py`

### 输入 / 备份

- 输入：`华东师范大学硕士论文.docx`
- 执行前自动备份为带时间戳的 `.bak` 文件

### 处理步骤

1. 为摘要、ABSTRACT、章节/节/小节标题、图目录、表目录、参考文献、致谢、附录设置大纲级别（1–3 级对应）。
2. 清空「目录」标题之后、「图目录」标题之前的全部旧条目（含误混入的图/表条）。
3. 在「目录」下插入 Word `TOC \o "1-3" \h \z \u` 域；若摘要 / ABSTRACT / 图目录 / 表目录未能可靠进入 TOC，则补书签条目或静态带 `PAGEREF` 的入口项。
4. 扫描正文题注，清空并重建「图目录」「表目录」：
   - 图：匹配 `图\d+-\d+` 题注段
   - 表：匹配 `表\s*\d+-\d+` 题注段
   - 过滤正文引用句（含「如图所示」等）
   - 缺失书签则自动补书签
   - 条目使用超链接 + `PAGEREF` + 点引导线
5. 应用居中标题、左对齐条目、字体与 tab 位样式。

### 页码策略

- 主目录：`TOC` 域
- 图/表目录：`PAGEREF` 书签域
- 脚本不写死最终页码；用户在 WPS/Word 中「更新域」一次完成刷新

## 验收标准

- 主目录不再出现任何图/表条目
- 主目录含摘要、ABSTRACT、图目录、表目录入口，以及章节至三级
- 图目录条目数与正文图题注一致（预期约 17）
- 表目录条目数与正文表题注一致（预期约 11），无重复编号
- 编号保持 `图3-1` / `表5-1`
- 打开文档更新域后，页码可正确显示

## 非目标

- 不改正文图/表编号格式（不改为点号）
- 不改章节正文内容
- 不自动提交论文 docx 到 git（除非用户另行要求）

## 风险与回退

- TOC 域在部分 WPS 版本需手动更新；脚本保存后给出操作提示
- 若题注识别漏检/误检，以备份 `.bak` 回退并收紧匹配规则
