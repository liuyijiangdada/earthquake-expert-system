## 四、GraphRAG / KnowledGPT 表述边界

- **1.2.3** 综述定位：开放域 RAG 与 KG 结合的代表工作。  
- **5.4.2** 设计对比：从图谱粒度、阶段感知、实时动态源、显式调度等维度对比**设计增益**，强调地震应急「阶段差异 + 时效」场景。  
- **禁止表述**：不编造 GraphRAG / KnowledGPT 在相同 60 题设定下的复现分数；对比为概念与设计层面，非同条件实验数值。

## 五、对照导师意见逐条说明（意见一～十）

| 意见 | 导师关切 | 6 章修改版落点 |
|------|----------|----------------|
| **一** | 第三章空洞 / 与后文脱节 | 取消空「总体方法章」；**第 3 章**静态知识构建、**第 4 章**协同调度为方法实体；**1.4** 组织结构、**3.1/4.1** 动机与衔接段写明三章环环相扣（3→4→5） |
| **二** | 图谱构建不具体 | **3.3** 完整 pipeline：数据来源与格式 → **特征抽取**与预处理 → 模式设计 → 导入与统计（含 **Cypher** 示例） |
| **三** | 向量检索空洞 | 并入 **3.4** 基于向量的应急文档检索；写 Topic 分块、索引及与图谱的互补，并服务第 4 章调度 |
| **四** | 协同主体不明 | **4.2** 定义 **静态知识**（图谱 + 向量索引）与 **动态知识**（CEIC/USGS 等）；**4.4/4.5** 三阶段分类、规则阈值与融合机制 |
| **五** | 章过多 | 重组为 **6 章制**（绪论 → 技术基础 → 静态知识 → 协同调度 → 系统与实验 → 总结展望） |
| **六** | 约 70 页 | 加厚 **第 3–5 章** + **附录**（问集、配置、Cypher 等）；插图位预留（如 `docs/superpowers/architecture/fig-6-1-*.png`） |
| **七** | GraphRAG 等对比 | **1.2.3** 综述 + **5.4.2** 设计对比表；明确**未**做同设定数值复现 |
| **八** | 消融样本小 | 主实验改为 **60 题**全量消融（**5.3–5.5**）；数据来自上述 JSON |
| **九** | B2 解释不足 | **5.5.3** B2 事实分偏低的方法根因：分块粒度、嵌入、Top-K、可核对片段依赖、评分 proxy 特性及改进方向（不以「样本小」搪塞） |
| **十** | 国内文献少 | **1.2.1** 国内地震应急知识管理与信息服务（《**自然灾害学报**》《**地震研究**》等 ≥5 篇）+ **参考文献** 增补 |
