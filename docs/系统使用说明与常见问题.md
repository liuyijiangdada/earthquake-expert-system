## 1. 快速启动

### 1.1 环境准备

```bash
cd /path/to/biyelunwen
source .venv/bin/activate    # 使用项目虚拟环境（见下文 FAQ）
pip install -r requirements.txt
```

### 1.2 启动依赖服务

```bash
# Neo4j（知识图谱，当前为强依赖）
docker compose up -d neo4j

# Milvus（可选；不启用时可在 config.py 设 RAG_USE_MEMORY_RAG = True）
docker compose up -d
```

### 1.3 启动应用

```bash
python app.py
```

浏览器访问：**http://127.0.0.1:8000**

前端修改后需构建：

```bash
cd frontend && npm run build
```

## 2. 功能说明

### 2.1 文字问答

- 输入框发送 → `POST /api/query`（`query_type: llm`）
- 使用 **Qwen1.5-1.8B + LoRA** 微调模型
- 自动注入：知识图谱、应急知识 RAG、阶段分类、调度器、USGS 动态数据（按配置）

### 2.2 图片问答（Qwen2-VL）

- 点击 **「上传图片」** → **「发送图片」**
- 走 `POST /api/multimodal-query`，使用 **Qwen2-VL-2B-Instruct**（首次请求时懒加载）
- 与纯文字发送是**不同接口**，不会自动根据内容切换模型

**模型下载（离线部署前）：**

```bash
export HF_ENDPOINT=https://hf-mirror.com   # 国内可选
unset HF_HUB_OFFLINE TRANSFORMERS_OFFLINE
huggingface-cli download Qwen/Qwen2-VL-2B-Instruct
```

### 2.3 最近三轮对话记忆

- 发送文字或图片时，前端会把界面中**已有最多 3 轮**对话发给后端
- 写入 prompt 的 `【最近对话】` 段，**不是**服务端数据库记忆
- 清空对话或刷新页面后历史消失
- 配置：`config.py` → `CHAT_HISTORY_MAX_ROUNDS = 3`

### 2.4 回答下方的示意图

- 由 `multimodal_output` 根据关键词匹配 `data/multimodal_resources.json`
- 图片资源托管在 **`/emergency-media/*.svg`**（本地静态文件）
- 仅展示在界面，**默认不写入** LLM 的文本 prompt

### 2.5 高德 Web 服务（静态地图 / 地理编码 / 步行规划）

1. 复制 `.env.example` 为 `.env`，填入 [高德开放平台](https://console.amap.com/dev/key/app) 申请的 **Web 服务** Key：
   ```bash
   AMAP_WEB_SERVICE_KEY=你的Key
   ```
2. 重启 `python app.py`；日志出现「高德 Web 服务已启用」即成功。
3. 静态图经服务端代理 `GET /api/amap/static-map`，**不会把 Key 暴露给浏览器**。
4. USGS 震中坐标会自动 **WGS84→GCJ-02** 再调用高德；避难所问句会尝试 **地理编码** 与 **步行路径规划**。

未配置 Key 时自动降级为 OpenStreetMap 示意图 + `uri.amap.com` 链接。

## 3. 常见问题（FAQ）

### Q1：`source .venv/bin/activate` 是干什么的？

激活项目自带的 Python 虚拟环境，使 `python` / `pip` 使用本项目已安装的包（如 `qwen-vl-utils`、`torchvision`），避免误用 conda `base` 等其它环境。

退出：`deactivate`

---

### Q2：Neo4j 连接失败 `Connection refused :7687`

**原因：** Neo4j 未启动。

**处理：**

```bash
docker compose up -d neo4j
docker ps | grep neo4j
```

确认 `config/config.py` 中 `NEO4J_URI`、`NEO4J_USER`、`NEO4J_PASSWORD` 与 `docker-compose.yml` 一致（默认 `neo4j` / `password`）。

---

### Q3：多模态报错 `RuntimeError` / 缺 `torchvision`

**原因：** `qwen-vl-utils` 依赖 `torchvision` 未安装。

**处理：**

```bash
source .venv/bin/activate
pip install torchvision qwen-vl-utils -i https://pypi.tuna.tsinghua.edu.cn/simple
```

重启 `python app.py`。

---

### Q4：多模态报错 `Invalid buffer size: 18.80 GiB`

**原因：** 图片分辨率或视觉 token 过大，Mac MPS 显存不足（且文本大模型可能已常驻内存）。

**处理：**

- 使用「上传图片」流程（已自动压缩）
- 调小 `config.py`：`QWEN_VL_MAX_IMAGE_EDGE`、`QWEN_VL_MAX_PIXELS`
- 换更小图片；关闭其它占 GPU 程序

---

### Q5：示意图显示 “The image is generating… refresh page”

**原因（已修复）：** 旧配置使用在线文生图 API 地址，返回的是生成中页面而非图片文件。

**当前方案：** 示意图改为 `static/emergency/*.svg`，URL 为 `/emergency-media/...`。修改 JSON 后需**重启** `app.py`。

---

### Q6：`TypeError: unsupported operand type(s) for |: 'type' and 'NoneType'`

**原因：** Python 3.9 不支持 `list | None` 类型注解（需 3.10+）。

**处理：** 使用 `.venv`（3.9）时项目已改为 `Optional[List]`；请拉取最新代码并重启。

---

### Q7：端口 8000 被占用 `Address already in use`

```bash
lsof -ti :8000 | xargs kill -9
python app.py
```

---

### Q8：pip 安装超时 `Read timed out`

使用清华镜像并加长超时：

```bash
pip install <包名> -i https://pypi.tuna.tsinghua.edu.cn/simple --default-timeout=300
```

`huggingface-hub` 建议保持 `<1.0`，与 `transformers` 兼容。

## 4. 配置速查（`config/config.py`）

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `RAG_USE_MEMORY_RAG` | False | True 时不连 Milvus |
| `RAG_MILVUS_REBUILD_ON_START` | True | 每次启动重建 Milvus（开发可改 False） |
| `QWEN_VL_ENABLED` | True | 关闭则图片接口 503 |
| `DEBUG_PAYLOAD_ENABLED` | True | False 时 API 不返回 `debug` 字段 |
| `SCHEDULER_STATIC_CONFIDENCE_THRESHOLD` | 0.9 | 静态知识置信度高时优先本地库 |
| `SCHEDULER_DYNAMIC_CONFIDENCE_THRESHOLD` | 0.4 | 动态源可用性阈值 |
| `DYNAMIC_CHINA_FILTER_ENABLED` | True | USGS 仅拉取中国范围事件 |
| `LAYER3_ENABLED` | True | 第三层增强总开关 |
| `LAYER3_INJECT_PROMPT` | False | 避难所/震中摘要写入 prompt |
| `MULTIMODAL_INJECT_PROMPT` | False | True 时将示意图摘要写入 LLM prompt |
| `CHAT_HISTORY_MAX_ROUNDS` | 3 | 多轮对话注入轮数 |
| `UPLOAD_IMAGE_MAX_EDGE` | 1280 | 上传压缩最长边 |
| `QWEN_VL_MAX_IMAGE_EDGE` | 768 | VL 推理前缩放 |

## 5. API 一览

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/query` | `llm` 文字问答；`kg` 图谱查询 |
| POST | `/api/multimodal-query` | 图片 + `input` + 可选 `history` |
| POST | `/api/update-data` | 刷新 USGS → Neo4j |
| POST | `/api/phase-classify` | 单独阶段分类 |
| GET | `/emergency-media/<file>` | 应急示意图静态资源 |
| GET | `/generated-media/<file>` | 余震时序图等动态生成资源 |
| GET | `/api/eval-set?phase=震中` | 分阶段评测问集（论文实验） |
